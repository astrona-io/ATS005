# Lab 012: Group Creation, Membership & the Active-Group Trap

Welcome to the Module 2 targeted practice sandbox. In this lab, you will create a group with a pinned GID, add existing users as supplementary members, rename a legacy group without losing its GID or membership, and delete a genuinely unused group.

## Launching the Lab
Run the following command in your terminal to boot the QEMU VM:
```bash
astrona run --git git@github.com:astrona-io/ATS005.git -c labs/lab-012
```
