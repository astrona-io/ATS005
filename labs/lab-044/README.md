# Home Directories For Directory Users Lab

Welcome to an arrivals mission, astronaut. The fleet registry knows every crew member, but nobody has built them a cabin.

Your job is to make the login steps create a home on first login, stocked with a welcome note.

## Launching the Lab

Run this command to start the virtual machine:

```bash
astrona run --git ssh://git@github.com/astrona-io/ATS005.git -c labs/lab-044
```

Open a terminal on it:

```bash
astrona ssh ats-005-lab-044
```

When you think you have finished, send it for grading:

```bash
astrona submit -c labs/lab-044
```

When you are done, remove the lab:

```bash
astrona destroy ats-005-lab-044
```
