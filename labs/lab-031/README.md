# Lab 031: System-Wide and Personal Environment Variables

Welcome to the Module 1 targeted practice sandbox. In this lab, you will set a proxy variable system-wide using the correct PAM-parsed drop-in, and set a personal editor preference for exactly one user without touching any other account.

## Launching the Lab
Run the following command in your terminal to boot the QEMU VM:
```bash
astrona run --git git@github.com:astrona-io/ATS005.git -c labs/lab-031
```
