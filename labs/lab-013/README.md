# Lab 013: Account Defaults, Password Aging & Locking

Welcome to the Module 3 targeted practice sandbox. In this lab, you will provision an account using the system's real confirmed defaults, force a password reset, set a hard account-expiration date, lock an account under investigation, and remove a fully offboarded account.

## Launching the Lab
Run the following command in your terminal to boot the QEMU VM:
```bash
astrona run --git git@github.com:astrona-io/ATS005.git -c labs/lab-013
```
