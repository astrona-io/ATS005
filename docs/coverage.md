# Curriculum and lab coverage

18 labs and 14 playgrounds are included in the environment matrix. This index connects the declared learning outcomes, lesson pages and executable assessment scenarios. A scenario being listed here does not mean its runtime checks have passed; use the PR's `all-environments-pass` result and uploaded logs for that evidence.

Every lab starts fresh, must fail an intended unfinished task, runs its reference solution as `student`, then runs every configured grader. Regression cases restore the solution and rerun all graders. Reboot checks apply where the scenario lists them. Every playground runs bootstrap, readiness checks and the smoke scripts listed in its `testing/scenario.json`.
