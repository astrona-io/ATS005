# Lab 032: Safe PATH Extension & Precedence

Welcome to the Module 2 targeted practice sandbox. In this lab, you will persistently append a personal scripts directory to `PATH` the safe way, and prove a same-named decoy script never shadows a real system command.

## Launching the Lab
Run the following command in your terminal to boot the QEMU VM:
```bash
astrona run --git git@github.com:astrona-io/ATS005.git -c labs/lab-032
```
