# ACL Tree Backup And Restore Lab

Welcome to a guest-list mission, astronaut. A careless cleanup is about to wipe every ACL on the ledger tree, so you will photograph the lists first.

Your job is to save the ACLs, survive the cleanup, restore them, and then take one visitor off the whole tree.

## Launching the Lab

Run this command to start the virtual machine:

```bash
astrona run --git ssh://git@github.com/astrona-io/ATS005.git -c labs/lab-024
```

Open a terminal on it:

```bash
astrona ssh ats-005-lab-024
```

When you think you have finished, send it for grading:

```bash
astrona submit -c labs/lab-024
```

When you are done, remove the lab:

```bash
astrona destroy ats-005-lab-024
```
